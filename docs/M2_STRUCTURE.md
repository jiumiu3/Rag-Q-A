# M2 结构化数据说明

## 输入门禁

M2 仅接受同时满足以下条件的 M1 文档：

- `manifest.is_complete=true`；
- `manifest.page_count == manifest.source_page_count`；
- `pages.raw.jsonl` 行数与清单页数一致；
- 页码从 1 开始连续且顺序正确。

任何条件不满足时拒绝解析，也不会创建 `data/processed` 输出。

## 处理流程

```text
完整 PageOCR
→ corrections.yaml 内存补丁
→ 页眉/页脚/重复及几何水印过滤
→ 目录页排除
→ 条款号与层级栈
→ 跨页条款合并
→ 术语、表题、图题识别
→ 表格坐标行聚类
→ KnowledgeUnit
→ 解析质量报告
```

清理仅影响 M2 内存副本。每个条款和知识单元仍通过 `SourceSpan` 指向 M1 原始页码、坐标、页面图片和 OCR block ID。

## 人工补丁

支持三种操作：

- `replace_text`：按 `page_number + block_id + old_text` 校验后替换；
- `drop_block`：删除确认属于水印或噪声的块；
- `exclude_page`：从结构解析中排除整页。

每次操作都会写入 `applied_corrections`，未命中或原文不一致的补丁不会静默生效。
