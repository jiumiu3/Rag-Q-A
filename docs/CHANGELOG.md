# 变更记录

## 2026-08-04：修复 M11 真实误差

- 条款/表格编号查询分别限定知识单元类型，并改为确定性 `exact-only` 路由。
- 明确编号不再调用语义相似结果冒充指定条款；开放问题仍使用 BM25 与语义向量。
- 数值校验排除标准号、条款号、年份、页码等引用数字。
- 结构化生成或后置校验降级时保留 `knowledge_search` 工具审计。
- 结构化失败仅记录脱敏错误类型，不保存模型原始失败输出。
- M11 新增模型生成成功率，防止抽取式降级被工具调用率掩盖。
- 81 项测试通过；最终固定评测集 0 个失败检查，未将结果外推到未评测场景。
