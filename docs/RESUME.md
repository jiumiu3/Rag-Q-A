# 项目摘要

项目已完成 M0-M11：3 份规范、166 页 OCR、1092 个知识单元，具备规范问答、设计拆解、人工确认、条件追问、确定性规则执行、会话工作流、API/Web 演示和可复现评测。

M11 固定数据集版本为 `m11-datasets-v1`。本次真实运行结果见 `evaluation/reports/latest/report.md`，包括 50 条检索、30 条问答、30 段拆解和 20 条合规执行夹具。三类演示均达到预期终态。

尚不能声称的能力：自由文本问答领域正确率、真实条款规则抽取准确率、生产端到端合规准确率、复杂表格自动查值。细粒度拆解夹具仍待领域负责人签字，当前也没有独立优化前基线，因此不报告性能提升。

后续优先事项是领域专家标注独立测试集、确认生产规则库，以及使用多模态方案对 27 张人工复核表格做对照实验。
